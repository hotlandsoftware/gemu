An arcade adaptation of Super Mario Bros. running on Nintendo's VS. UniSystem hardware. Uses the same RP2A03 CPU as the NES but with an RP2C04-0004 PPU, which has a scrambled color palette unique to this board. The game features rebalanced difficulty, additional enemies, and six bonus levels taken from Super Mario Bros. 2 (the Japanese version).

DIP switches control difficulty, bonus life threshold, starting lives, and coinage. Use dipswitch list in the GEMU monitor to see current settings, or dipswitch <name> <value> to change them.
