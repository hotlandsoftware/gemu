Destroyer is an arcade game produced by Spanish company Cidelsa in 1980. Space Invaders-style shoot-em-up.

This machine supports dip switches. You can use dipswitch list in the GEMU console for a list and dipswitch (name) (value) to set the value.

Run
./bin/gemu -M destroyer -rom /path/to/roms/destroyer/
